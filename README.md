# LiveBeer iOS App

Мобильное приложение программы лояльности для клиентов LiveBeer.

## Технологический стек

### Основные технологии
- **Swift 5.0** - язык программирования
- **SwiftUI** - UI фреймворк
- **iOS 18.5+** - минимальная версия ОС
- **Xcode** - среда разработки

### Архитектура
- **MVVM-C** (Model-View-ViewModel-Coordinator)
  - Модульная структура с разделением на экраны
  - Координатор для управления навигацией
  - ViewModel для бизнес-логики

### Хранение данных
- **UserDefaults** - для хранения сессии пользователя
- **SessionStorage** - сервис для управления авторизацией

### Дополнительные фреймворки
- **CoreImage** - генерация штрихкодов (Code128)
- **Foundation** - базовые типы и утилиты

### Тестирование
- **Swift Testing** - unit тесты

## Структура проекта

```
LiveBeer/
├── App/                    # Точка входа и координатор
├── Core/                    # Общие компоненты
│   ├── Components/          # Переиспользуемые UI компоненты
│   ├── DesignSystem/        # Дизайн-система (цвета, типографика, отступы)
│   ├── Models/              # Модели данных
│   └── Services/           # Сервисы (форматирование, авторизация, штрихкоды)
└── Modules/                 # Модули приложения
    ├── Welcome/             # Приветственный экран
    ├── PhoneInput/          # Ввод телефона и кода активации
    ├── GuestLogin/          # Гостевой вход
    ├── Home/                # Главный экран с табами
    ├── Information/         # Информация
    ├── Stores/              # Магазины
    └── Profile/             # Профиль
```

## Реализованные экраны

1. **Welcome** - Приветственный экран с выбором входа/регистрации/гостевого режима
2. **PhoneInput** - Ввод номера телефона с форматированием и валидацией
3. **ActivationCode** - Ввод кода активации (4 цифры)
4. **Home** - Главный экран с табами (Главная, Информация, Магазины, Профиль)
   - Карточка с баллами лояльности
   - Карточка с прогрессом литров
   - Штрихкод для накопления
   - Новости и акции

## Требования

- Xcode 15.0+
- iOS 18.5+
- Swift 5.0+
